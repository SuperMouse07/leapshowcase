单进程 Express 应用，按职责拆分为三个核心文件：`server.js` 作为入口挂载 CORS、JSON 解析中间件，定义 `authRequired`/`adminOnly`/`bearerAdmin` 鉴权中间件，注册 `/api/auth/*`（登录、获取当前用户）、`/api/products/*`（公开读 + 管理员写）、`/api/slides/*`（轮播图管理）、`/api/settings/*`（全站设置 upsert）、`/api/stats/storage`（存储统计）与 `/api/health` 健康检查路由，并在检测到 `../frontend` 目录时托管静态资源以支持 Zeabur 单进程部署；`db.js` 实现数据库抽象层，启动时根据 `DATABASE_URL`/`PGHOST`/`POSTGRES_*` 环境变量动态选择 `pg` Pool（PostgreSQL）或 `sql.js` WASM（SQLite），统一暴露 `connect()`/`initSchema()`/`db.query`/`db.run` 代理对象，并在 SQLite 模式下每次写操作后通过 `fs.writeFileSync` 持久化到 `data/leapchess.db`；`seed.js` 在启动时执行幂等种子数据（管理员/客户账户 + 占位商品）。依赖方向单向：`server.js` → `db.js` + `seed.js`，无反向引用。所有 SQL 查询使用 `?` 占位符，由 `db.js` 在 PostgreSQL 路径下通过 `toPgSql` 转换为 `$1/$2...`，避免 SQL 注入。图片上传采用 data URL 入参、SHA1 内容哈希命名落盘至 `UPLOAD_DIR`（默认 `backend/data/uploads`，生产可经 `UPLOAD_DIR` 指向 Volume），并通过 `express.static('/uploads')` 提供长缓存静态访问。
