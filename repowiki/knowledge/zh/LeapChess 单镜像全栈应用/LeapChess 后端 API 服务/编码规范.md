- 所有 SQL 查询统一使用 `?` 占位符参数化，由 `db.js` 在 PostgreSQL 路径下通过 `toPgSql` 自动转换为 `$1/$2...`，避免 SQL 注入。
- 敏感写操作（新增/更新/删除商品、轮播图）通过链式挂载 `authRequired` 与 `adminOnly` 中间件实现基于角色的访问控制。
- 数据库连接采用延迟初始化模式：模块导出代理对象，调用 `query/run` 前必须 `await connect()`，未连接时抛出明确错误。
- 建表语句在 `initSchema` 中按 `usePg` 分支编写，保证 SQLite 与 PostgreSQL 语义一致且幂等（IF NOT EXISTS）。
- 平滑迁移通过 `ensureColumn` 检测缺失列后 `ALTER TABLE ADD COLUMN`，兼容旧库结构。
- 图片与变体字段通过 `toImages`/`toVariants` 工具函数归一化输入，兼容旧单图字段、JSON 字符串与数组三种格式，并限制最多 `MAX_IMAGES` 张。
