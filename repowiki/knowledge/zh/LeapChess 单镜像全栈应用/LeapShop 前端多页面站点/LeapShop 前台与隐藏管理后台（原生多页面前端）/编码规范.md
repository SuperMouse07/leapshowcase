- 页面通过 `<body data-page="...">` 标识当前路由，site.js 据此高亮对应导航项并决定激活状态。
- 所有用户输入渲染前统一调用 `escapeHtml`（来自 store.js 或 api.js）后再拼入 innerHTML，防止 XSS。
- API 调用采用自动探测模式：优先尝试同源 `/api/health`，失败后降级为 `location.hostname:3000/api`，对网络异常做静默降级。
- 商品主图统一经 `withCover`/`productImage` 处理，优先取 `images[0]`，缺失时回退到 `assets/placeholder.svg`。
- 购物车状态以 `Map` 内存态 + `localStorage` (`pf_cart`) 双写，存储不可用时自动降级为纯内存态，保证功能可用。
- 全站交互事件通过单一 `document.addEventListener('click', ...)` 事件委托处理，按 `data-*` 属性（如 `data-add`、`data-step`、`data-remove`）分发逻辑。
