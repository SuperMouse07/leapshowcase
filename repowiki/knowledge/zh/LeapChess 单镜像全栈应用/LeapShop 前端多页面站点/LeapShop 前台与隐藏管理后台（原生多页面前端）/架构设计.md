模块采用传统多页面（SPA-less）架构：每个 `.html` 页面通过 `<script type="module">` 引入 `js/site.js`（注入统一导航栏、购物车抽屉、页脚、滚动显现观察器）和对应业务脚本（home.js、products.js、product.js、category.js、journey.js、chess-clock/board/stopwatch/lifestyle 各一）。依赖方向自顶向下：HTML → site.js（全局布局 + 跨页购物车状态）→ store.js（只读数据层，封装 `/api/products`、`/slides`、`/settings` 并做模块级缓存）→ api.js（admin 专用写接口，带 Bearer Token）。所有页面以 `<body data-page="...">` 标识路由，site.js 据此高亮导航项。样式集中在 `css/style.css`，使用 CSS 自定义属性定义白底金黑主题，动效由 CSS transition/animation 驱动，JS 仅切换类名。`sandbox/` 保留设计阶段 prototype-a~f 与设计参考素材，与生产代码解耦。
