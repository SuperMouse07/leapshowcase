### LeapShop / LeapChess 官网
- 定义：本项目的业务名称，指参考 theleapchess.com 风格重构的国际象棋主题电商官网全栈应用，包含用户认证、角色权限与商品 CRUD 功能。
- 别名：LeapShop、LeapChess 官网、theleapchess.com

### 超级管理员
- 定义：系统内置的高权限角色（用户名 `P001`），拥有浏览全部内容与商品上传/编辑/删除的完整管理权限。
- 别名：P001、admin

### 客户
- 定义：系统内置的低权限角色（用户名 `C001`），仅能浏览基础内容与商品详情，对写操作返回 403。
- 别名：C001、customer

### 单服务模式
- 定义：后端 Express 服务同时承担 API 与静态页面托管的职责，一个进程对外提供 `/`、`/login.html`、`/admin.html` 及所有 `/api/*` 接口，便于 Zeabur 单服务部署。
- 别名：单服务

### 冒烟测试
- 定义：项目自带的端到端验证脚本，`test-api.ps1` 覆盖登录、鉴权、商品 CRUD 等 15 项流程用例，用于快速确认后端 API 可用性。
- 别名：API 冒烟测试、test-api.ps1
